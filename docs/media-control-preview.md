# Media control HTML preview

Both C# and TypeScript screen renderers dispatch HmiMediaControl to a dedicated unloaded preview. Existing Source and AutoPlay properties survive as escaped metadata; source text and explicitly configured autoplay settings are also visible. Expressions remain engineering configuration, and missing autoplay remains unspecified. Common geometry, appearance and screen-item attributes use the shared renderer path.

The preview does not load or play media. Optional toolbar/status-bar visibility and colors are retained as metadata; enabled bars show unloaded command/status regions. VideoOutput retains the raw UInt32 scaling configuration without guessing enum meanings. Unified maps Url to Source after the legacy key, including explicit empty values. Native media resources, runtime commands, bar elements/fonts/layout, semantic video scaling and engineering-preview fidelity still need coverage. Synthetic tests exercise escaped source text, true/false/unspecified autoplay, expression fallback and unloaded output. Renderer regression suites passed 490 C# and 434 TypeScript checks.

ToolbarFont and StatusBarFont independently style visible bar regions and resolve existing LocalizedFonts for the requested LCID. Shared renderer checks cover locale selection, hidden bars and no source mutation. Unified resolves nested bar font references through its existing font reader; preserving all cultures from Unified resources is separate outstanding work. Validation for this increment: 491 C# and 435 TypeScript renderer checks, 8 C# and 8 TypeScript related parser checks, both TypeScript builds and all Base framework builds.
