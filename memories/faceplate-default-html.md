# Faceplate defaults in HTML

C#/TS HmiScreenToHtmlConverter merges ordinary InterfaceProperties defaults into the local instance scope only when no explicit entry reserves that name. Null/invalid/tag entries retain existing control-static fallback rather than receive a default. First eligible non-tag instance duplicate, first eligible default and ordinal case matching remain deterministic. TagInterfaceProperties and IsTag members are excluded. Standalone definitions use their own defaults; nested/repeated instances replace their parent scope. Existing typed consumers handle text, Boolean, numeric, color and image values without mutating models.

Faceplate default preview increment: shared C#/TS HTML scopes now merge ordinary interface member defaults only for names absent from all explicit instance entries. Explicit null/invalid/tag entries reserve a name and keep existing control-static fallback; first eligible non-tag instance duplicate and ordinal case matching stay unchanged. Tag-interface collections/members are excluded. Standalone faceplate conversion uses its own defaults; nested/repeated instances keep independent scopes. Existing text/Boolean/numeric/color/image consumers use the values without model mutation. This is stored-model preview behavior, not proof of native/runtime precedence.

Validation: 17 new synthetic shared cases per language; full shared suites passed 5714 C# and 5682 TS checks without skips. Both TS builds and all three shared C# targets passed. Main C#/TS selected suites each passed 22 checks without skips, extending generic raw/compressed image-default attributes through the public renderer. Effective-value inspection, native default encoding/version/export/visual comparisons, dynamic/compound/decimal literals and the full screen/recipe/HMI objective remain open.
